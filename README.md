# 3dfolio

A personal portfolio website built with **React**, **Vite**, **Three.js**, and **TailwindCSS**.

## Features

- Interactive 3D elements using [three.js](https://threejs.org/) and [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber/getting-started/introduction)
- Animations with [framer-motion](https://www.framer.com/motion/)
- Responsive design with [TailwindCSS](https://tailwindcss.com/)
- Timeline and tilt effects
- Contact form powered by [EmailJS](https://www.emailjs.com/)

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16 or newer recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/niranjansah87/Personal_Portfolio_Using_React.git
cd Personal_Portfolio_Using_React
npm install
```

### Development

Start the development server:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view it in your browser.

### Build

To create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
